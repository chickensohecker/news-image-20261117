The world in one day: a one-page newspaper front page summing up Tuesday,
17 November 2026 — Ukraine strikes the Crimea bridge again as Russia hits
Kyiv's crossings, Iranian drones target a US radar in Bahrain, Xi, Trump and
Putin are set to meet in Shenzhen, Nvidia reports after its spy scandal, and
winter rains deepen the crisis in Gaza.

`main.py` draws the whole page in code — a bitmap font, a layout engine and
a pure-stdlib PNG writer — and writes it to `/output/entry.png`. No network,
no third-party packages, and the same bytes on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
